Roteiro de Prática: Formatação em Java

Atividade prática para execução em sala de aula

1. Objetivos da prática

Ao final da atividade, o aluno deverá ser capaz de:

  • Diferenciar print, println e printf.
  • Utilizar especificadores de formatação em Java.
  • Exibir números inteiros, textos e números decimais formatados.
  • Montar frases combinando texto e variáveis.

2. Conteúdo necessário

Antes de começar, revise os principais comandos:

Comando / Especificador Uso
System.out.print() Exibe uma mensagem sem pular linha.
System.out.println() Exibe uma mensagem e pula para a próxima linha.
System.out.printf() Exibe uma saída formatada.
%s Texto.
%d Número inteiro.
%f Número real.
%.2f Número real com duas casas decimais.
%c Caractere.
%b Valor booleano.
%n Quebra de linha.

3. Preparação

  1. Abra sua IDE Java.
  2. Crie um novo projeto.
  3. Crie uma classe chamada Formatacao.
  4. Adicione o método main.
  5. Execute cada etapa da atividade separadamente.

4. Prática 1 - print e println

Digite e execute o código abaixo:

public class Formatacao {
    public static void main(String[] args) {

        System.out.print("Olá ");
        System.out.print("Turma!");

        System.out.println();

        System.out.println("Aprendendo Java");
        System.out.println("Formatação de saída");
    }
}

Observe

  • Qual a diferença entre print e println?
  • O que acontece quando usamos System.out.println(); sem texto?

5. Prática 2 - printf com texto e números inteiros

public class Formatacao {
    public static void main(String[] args) {

        String nome = "Carlos";
        int idade = 18;

        System.out.printf("Nome: %s | Idade: %d", nome, idade);
    }
}

Saída esperada:

Nome: Carlos | Idade: 18

Faça uma alteração

Troque o nome e a idade pelos seus próprios dados.

6. Prática 3 - Números decimais

public class Formatacao {
    public static void main(String[] args) {

        double preco = 12.5;

        System.out.printf("Preço: R$ %.2f", preco);
    }
}

Observe que %.2f determina que o número seja exibido com duas casas decimais.

Teste também

double media = 8.4567;

System.out.printf("Média: %.1f%n", media);
System.out.printf("Média: %.2f%n", media);
System.out.printf("Média: %.3f%n", media);

Compare os resultados.

7. Prática 4 - Montando uma frase formatada

Crie as seguintes variáveis:

String aluno = "Mariana";
int idade = 17;
double nota = 8.75;

Depois, mostre os dados usando apenas um printf:

System.out.printf(
    "Aluno: %s | Idade: %d | Nota: %.2f",
    aluno, idade, nota
);

Saída esperada:

Aluno: Mariana | Idade: 17 | Nota: 8.75

8. Prática 5 - Entrada de dados e formatação

Agora utilize Scanner para receber os dados do usuário.

import java.util.Scanner;

public class Formatacao {
    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        System.out.print("Digite seu nome: ");
        String nome = teclado.nextLine();

        System.out.print("Digite sua idade: ");
        int idade = teclado.nextInt();

        System.out.print("Digite sua nota: ");
        double nota = teclado.nextDouble();

        System.out.printf(
            "%nAluno: %s%nIdade: %d anos%nNota: %.2f%n",
            nome, idade, nota
        );
    }
}

Tarefa

Execute o programa pelo menos duas vezes utilizando valores diferentes.

9. Desafio 1 - Produto

Crie um programa que possua as variáveis:

  • nome do produto;
  • quantidade;
  • preço unitário.

O programa deverá mostrar uma saída semelhante a:

Produto: Teclado Quantidade: 2 Preço unitário: R$ 75.50

Utilize obrigatoriamente printf.

10. Desafio 2 - Boletim do aluno

Leia:

  • nome do aluno;
  • primeira nota;
  • segunda nota.

Calcule a média:

double media = (nota1 + nota2) / 2;

Depois apresente:

Aluno: Ana Souza Nota 1: 8.50 Nota 2: 7.00 Média: 7.75

Todas as notas deverão aparecer com duas casas decimais.

11. Desafio final - Nota fiscal simples

Crie um programa que receba:

  • nome do cliente;
  • nome do produto;
  • quantidade;
  • valor unitário.

Calcule:

double total = quantidade * valorUnitario;

Depois exiba uma pequena nota fiscal:

---------- NOTA FISCAL ---------- Cliente: João Silva Produto: Mouse Quantidade: 3 Valor unitário: R$ 45.90 Total: R$ 137.70 ---------------------------------

Utilize %s, %d, %.2f e %n.
